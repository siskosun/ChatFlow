# ChatFlow 0.3 界面原型

## 设计依据

- 技能：[benjitaylor/skills · Stageshow](https://github.com/benjitaylor/skills/tree/main/stageshow)。读取 `SKILL.md` 及 craft、framing、looks、kit、rehearse、verify、review、teaching 指导。
- 基础示例：`stageshow/examples/static-card`。沿用 React Stage、Window、Row 结构及静态构图方式，替换为 ChatFlow 的实际页面、动作与蓝灰设计变量。
- 产品依据：ChatFlow 0.3，提交 `609e0d346359664d88f9150c9eaca0c618a88eee` 的 `workspace/index.html`、`workspace/flow.js`、`workspace/style.css`。
- 本页只含合成对话、任务和文件。所有状态均为原型演示，不读取用户数据、不触发实际保存、发送或下载。

## 先决定页面要回答什么

| 画面 | 要识别的对象 | 下一步动作 | 点击后的结果 |
| --- | --- | --- | --- |
| 首页 | 两项主要功能 | 保存并继续对话 / 交出任务或回传结果 | 进入对应任务区 |
| 首次保存 | 当前选择的对话、文件范围 | 保存对话 | 显示保存进度；来源变化则停止 |
| 保存完成 | 已保存对话、消息及附件数量 | 继续到新对话 | 准备新的聊天；重新采集为次操作 |
| 交出任务 | 来源对话与任务内容 | 复制任务 | 生成带来源标记的任务文本 |
| 回传结果 | 检出的来源对话、结果内容 | 保存结果 / 复制结果并返回 | 保存到本地，再回到来源对话 |
| 备份等待 | 下载中的文件及已保存数量 | 等待当前下载，或取消并稍后重试 | 不把下载中状态称为完整备份 |

## 构图与视觉

静态可切换画面。默认宽屏 960px，紧凑画面 358px，分别布局，不缩小字号。主任务区居中，辅助导航低对比；每个任务区只有一个有色主按钮。使用 ChatFlow 蓝灰、系统字体、12–16px 正文与 44px 以上操作目标。浅色与暗色各有完整表面、文字、状态与焦点变量。

主体使用真实短文案与实际操作名称；不增加虚构导航或泛用 AI 图标。仅在流程状态需要时显示解释。保留“本地保存”“下载备份”“上传确认”“发送消息”的区别。

## 验证边界

先渲染原型，再对照实施生产页面。检查宽屏与 390px、320px 可读性，切换浅暗色，观察主操作层次及文字溢出。截图只证明这些合成画面已渲染；不代替真实登录环境、独立用户、真人或辅助技术验收。
