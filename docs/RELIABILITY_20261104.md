# 可靠性修订的验收契约

本文件说明 2026-11-04 的工程验收边界；执行状态仍以 Checkpoint 和准确提交的 CI 为准，不以本文件声明通过。

第一批代码提交 a74cde6d33796984cd8abea8bb5527d2b33485b2 包含：页面来源代次、任务选文的文档与代次复核、精确附件名确认、按消息及文件引用对账，以及 JSON 解析前的字节上限。接口响应上限分别为会话信息 1 MiB、完整对话 32 MiB、下载元信息 2 MiB；下载元信息包括 sandbox JSON 包装响应。读流、解析、规范化和持久化分别保持来源检查。

相同文件名或消息内出现序号不是文件身份。只有同消息中的明确文件 ID 或 sandbox 路径可以消解 DOM 附件提示；无法确认的记录保持未取得，不创建空文件。页面附件就绪仅是页面观察，不是模型读取或发送收据。自动上传只允许一个已关联输入区内的一次尝试，未知结果不切换粘贴或拖放重试。

正常测试与负向测试分别统计。固定反例中错误归属、错误附件就绪和错误身份定位均不得出现；正常的 API 保存、匹配文件引用、消息定位和手动发送仍须通过。保留全部旧浏览器断言，测试目标 HTML 仅增加与生产契约一致的显式 composer form；无关联输入区作为单独的未知状态用例，而不是生产测试开关。
